# Dictionary App

A modern, user-friendly web-based dictionary application that helps you quickly find the meanings and definitions of words you don't know.

## Features

- **Word Search**: Enter any English word to get its definition and meanings
- **Comprehensive Definitions**: Displays multiple definitions organized by part of speech (noun, verb, adjective, etc.)
- **Input Validation**: Ensures only valid alphabetical input is accepted
- **Error Handling**: Provides clear error messages for invalid inputs or words not found
- **Modern UI**: Clean, responsive interface with a beautiful background and smooth animations
- **Easy to Use**: Simple search interface with a close button to dismiss results

## How to Use

1. Open the application in your web browser
2. Type a word in the search input field (e.g., "Pirates")
3. Click the "Search" button or press Enter
4. View the word's definitions organized by part of speech
5. Click "Close" to dismiss the results and search for another word

## Technical Details

- **Frontend**: Pure HTML, CSS, and JavaScript
- **API**: Uses the [Dictionary API](https://dictionaryapi.dev/) to fetch word definitions
- **Styling**: Modern CSS with Montserrat font and responsive design
- **Validation**: Input validation ensures only alphabetic characters are accepted
